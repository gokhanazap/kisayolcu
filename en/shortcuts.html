Cheat sheet

All shortcuts

120 shortcuts in plain English. Source: Apple’s official list ↗ plus a few browser extras. Anything marked Try → has a hands-on drill.

⌘ The basics 16

Every day, in every app.

⌘commandC

Copy⭐ essential

Copies the selected text, file or image to the clipboard.

Try →
⌘commandV

Paste⭐ essential

Pastes the clipboard wherever your cursor is.

Try →
⌘commandX

Cut

Cuts the selected text. To move files in Finder, use ⌘C + ⌥⌘V.

Try →
⌘commandZ

Undo⭐ essential

Undoes the last thing you did. Keep pressing to go further back.

Try →
⇧shift⌘commandZ

Redo

Brings back what you just undid.

Try →
⌘commandA

Select All

Selects the entire text, list or folder.

Try →
⌘commandF

Find

Opens search in a page, a document or Finder.

Try →
⌘commandG

Find Next

Jumps to the next match. ⇧⌘G goes to the previous one.

⌘commandS

Save

Saves the document.

⇧shift⌘commandS

Save As / Duplicate

Makes a copy of the document.

⌘commandO

Open

Brings up the open-file dialog.

⌘commandP

Print

Opens the print (and save as PDF) dialog.

⌘commandN

New

Opens a new window or a new document.

⌘command,

Settings

Opens settings for the app in front. Works almost everywhere.

Try →
⇧shift⌘command?

Search the menus

Opens the Help menu. Type a command and it points to it in the menus.

⌥option⇧shift⌘commandV

Paste and Match Style

Pastes text so it matches the styling of wherever it lands.

Try →

⌥ Flying through text 18

Move the cursor without touching the mouse.

⌥option←/⌥option→

Jump word by word

Moves the cursor to the previous / next word.

Try →
⌘command←/⌘command→

Start / end of line

Moves the cursor to the start or end of the line.

Try →
⌘command↑/⌘command↓

Top / bottom of document

Moves the cursor to the very top or very bottom of the text.

Try →
⇧shift←/⇧shift→

Select letter by letter

Extends the selection by one character. ⇧↑ / ⇧↓ go line by line.

⌥option⇧shift←/⌥option⇧shift→

Select word by word

Extends the selection one word at a time.

Try →

Select to end of line

Try →
⇧shift⌘command↑/⇧shift⌘command↓

Select to end of document

Selects from the cursor to the top / bottom of the text.

⌥option⌫delete

Delete a word⭐ essential

Deletes the whole word to the left of the cursor in one go.

Try →
⌘command⌫delete

Delete the line

Deletes everything from the cursor back to the start of the line.

Try →
🌐fn⌫delete

Forward delete

Deletes the character to the right of the cursor (the Windows Delete key).

Try →
🌐fn↑/🌐fn↓

Page up / down

Page Up / Page Down. fn← and fn→ jump to the top / bottom.

⌘commandB

Bold

Makes the selected text bold. ⌘I for italic, ⌘U for underline.

⌘commandK

Add a link

Turns the selected text into a link (Notes, Mail, Slack, Notion…).

⌃controlA/⌃controlE

Start / end of line (secret route)

Old-school start / end of line that works everywhere, Terminal included.

Try →
⌃controlK

Cut to end of line

Cuts from the cursor to the end of the line. ⌃Y pastes it back.

⌃controlT

Swap two letters

Swaps the letters on either side of the cursor. A typo lifesaver.

Try →
⌃control⌘commandD

Look Up

Shows the definition of the word under the pointer.

⌘command;

Find a typo

Jumps to the next misspelled word in the document.

😀 Emoji & special characters 12

Emoji, €, ~ and friends. No googling.

⌃control⌘commandspaceor🌐fnE

Emoji picker⭐ essential

Opens the emoji and symbols picker. Just type to search.

Try →
🌐fn🌐fn

Character Viewer

Press the fn / 🌐 key twice (turn it on in Keyboard settings).

⇧shift2

@ sign⭐ essential

Types @ for emails and mentions. ⌨️ On non-US keyboards this key may differ.

⇧shift3

# sign

Types # for hashtags and code. ⌨️ On a UK keyboard, # is ⌥3.

⇧shift4

$ sign

Types a dollar sign.

[or]

Square brackets [ ]

Opens / closes a square bracket. The two keys right of P.

⇧shift[/⇧shift]

Curly braces { }

Opens / closes a curly brace. Essential for code.

\

Backslash \

Types a backslash. The key above Return. ⇧\ gives you |. ⌨️ On non-US keyboards this key may differ.

⇧shift`

~ tilde

Types a tilde (for paths like ~/Downloads). The key left of 1. ⌨️ On non-US keyboards this key may differ.

⌥option⇧shift2

€ sign

Types the euro symbol. ⌨️ On a UK keyboard, € is ⌥2.

⌥option⇧shiftK

 Apple logo

Types the Apple logo. Only shows up on Apple devices 😉

Try →
⌃controlspace

Switch keyboard language

Flips between your input sources (if you’ve added more than one).

▢ Windows & apps 18

Switch, hide, close, tile.

⌘command⇥tab

Switch apps⭐ essential

Cycles through open apps. Keep holding ⌘ and tap Tab again.

Try →
⌘command`

Switch windows of the same app

Flips between windows of the app you’re in. The ` key sits left of 1. ⌨️ On non-US keyboards, it’s the key next to left Shift or above Tab.

Try →
⌘commandW

Close window / tab

Closes the window or tab in front. The app stays open.

Try →
⌥option⌘commandW

Close all windows

Closes every window of the app.

⌘commandQ

Quit app⭐ essential

Actually quits the app. That’s the difference from ⌘W.

Try →
⌘commandH

Hide app

Gets the app out of sight without quitting it.

Try →
⌥option⌘commandM

Minimize all

Sends every window of the app down to the Dock.

⌥option⌘commandH

Hide Others

Hides every app except the one in front. Instant focus mode.

⌘commandM

Minimize

Shrinks the window into the Dock. ⌥⌘M does it for all of them.

Try →
⌥option⌘commandesc

Force Quit⭐ essential

Opens the Force Quit window so you can kill a frozen app.

Try →
⌃control⌘commandFor🌐fnF

Full screen

Takes the app in and out of full screen.

Try →
🌐fn⌃control←/🌐fn⌃control→

Tile window left / right

Split the screen in two (macOS 15 and later). fn⌃↑ / fn⌃↓ for top / bottom half.

Try →
🌐fn⌃controlF

Fill the screen

The window fills the screen (without going full screen). fn⌃C centers it.

🌐fn⌃controlR

Return to previous size

Puts a tiled window back to the size it was.

⌃control↑

Mission Control

A bird’s-eye view of every open window and desktop.

Try →
⌃control↓

App windows

Shows all windows of the app in front, side by side.

⌃control←/⌃control→

Switch desktops

Slides between desktops (Spaces) and full-screen apps.

Try →
🌐fnH

Show Desktop

Shoves every window aside to reveal the desktop.
